# Banking System CLI

A simple command-line banking system built with Python to practice Object-Oriented Programming (OOP), object interaction, lists, validation, and basic transaction management.

## Features

- Create a new bank account
- Prevent duplicate account numbers
- View account details
- Deposit money
- Withdraw money
- Transfer money between accounts
- Prevent transferring money to the same account
- Maintain transaction history
- Delete an account
- Input validation for invalid values
- Handles insufficient balance
